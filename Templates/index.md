# Templates

Note templates used by the skills and (optionally) Templater. Placeholders `{{date}}`,
`{{time}}`, `{{title}}`, `{{topic}}` are filled at creation time.

- `session.md` — agent session log (Context / Changes / Open threads / Decisions) ✅
- `daily.md` — daily note (Focus / Tasks / Active projects / Log / Captured) ✅
- `paper.md` — literature reading note (`@citekey`, bibliographic frontmatter, summary) ✅
- `concept.md` — atomic evergreen note (Definition / Intuition / Grounding / Open questions) ✅
- `moc.md` — Map of Content hub ✅
- `meeting.md` — dated meeting note ✅
