# Templates

Note templates used by the skills and (optionally) Templater. Placeholders `{{date}}`
and `{{time}}` are filled at creation time with the real ISO date/time.

- `session.md` — agent session log (Context / Changes / Open threads / Decisions) ✅
- `daily.md` — daily note (Focus / Tasks / Active projects / Log / Captured) ✅
- `paper.md` — literature reading note (`@citekey`, bibliographic frontmatter, summary) — _Phase 4_
- `concept.md` — atomic evergreen note — _Phase 4_
- `moc.md` — Map of Content hub — _Phase 4_
- `meeting.md` — dated meeting note — _Phase 4_
