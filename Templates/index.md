# Templates

Note templates used by the skills and by Templater. To be filled in during Phase 3–4:

- `paper.md` — literature reading note (`@citekey`, bibliographic frontmatter, structured summary)
- `concept.md` — atomic evergreen note
- `moc.md` — Map of Content hub
- `daily.md` — daily note
- `meeting.md` — dated meeting note
- `session.md` — agent session log (Context / Changes / Open threads / Decisions)
