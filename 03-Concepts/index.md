# 03 · Concepts

**Atomic evergreen notes — one idea each, in my own words, densely linked.** This is my
crystallized understanding, *concept-oriented* (organized by idea, not by source or
project). Filename = kebab-case concept name (`control-barrier-functions.md`).

Rules:
- One concept per note (so it can be linked/reused independently).
- Concept-oriented, not source-oriented: a concept collects thinking from *all* the
  papers that touch it — that collision is where synthesis happens.
- Every concept links to the [[02-Literature/index|papers]] that ground it (`[@citekey]`).
- Link generously to other concepts — but only when understanding A genuinely changes
  how I see B.
- **No timestamp IDs** — the descriptive title is the address (Obsidian propagates renames).

On concept notes the agent **drafts an editable base** (marked with an `ai-draft` callout) —
grounded in the linked papers, inference flagged, never fabricated — which I then refine into
my own words. Drafted via the `concept` skill.
