# 06 · Archive

**Completed or inactive material** — finished papers/talks/courses moved out of
[[01-Projects/index|Projects]], and superseded notes kept for the record.

Archiving ≠ deleting. Notes are never deleted (guardrail). Move a whole project folder
here when it's done; its links into Concepts/Literature keep working. When moving notes
that are linked elsewhere, use the Obsidian CLI (or rewrite inbound links + run the
link-check) so wikilinks don't break.
