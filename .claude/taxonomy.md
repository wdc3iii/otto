# Controlled tag vocabulary — otto

**Only tags in this file may be applied to notes.** Max 3 tags per note. Reuse an
existing tag before proposing a new one. To add a tag, propose it here first (don't add
silently). Tags are lowercase, kebab-case, and live in frontmatter as a YAML **list**.

This seed list is intentionally small — it grows deliberately, not organically.

## Domain
- `locomotion` — legged/humanoid locomotion
- `navigation` — navigation & autonomy
- `control` — classical control (CLF, CBF, MPC, optimal control)
- `rl` — reinforcement learning
- `planning` — motion/trajectory planning
- `hardware` — robots & compute (Unitree G1, `talos`, `amberlab`)

## Note role (optional, orthogonal to domain)
- `moc` — map of content
- `open-question` — unresolved question / research direction
- `method` — a technique/algorithm
- `to-revisit` — flagged for follow-up

_Add new tags below with a one-line definition. Keep the list tight._
