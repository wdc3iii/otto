# 05 · Resources

**Reference material that isn't a paper or a distilled concept:** code snippets,
configs, command cheatsheets, datasets, hardware notes (`talos`, `amberlab`, Unitree G1),
tool docs, boilerplate.

Not source-anchored like [[02-Literature/index|Literature]] and not a distilled idea like
[[03-Concepts/index|Concepts]] — this is the "useful to have on hand" bucket. Guard
against it becoming a graveyard: if a resource turns into understanding, promote it to a
concept and link back.
