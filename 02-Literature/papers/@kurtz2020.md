## Abstract
Approximate simulation, an extension of simulation relations from formal methods to continuous systems, is a powerful tool for hierarchical control of complex systems. Finding an approximate simulation relation between the full "concrete" system and a simplified "abstract" system establishes a bound on the output error between the two systems, allowing one to design a controller for the abstract system while formally certifying performance on the concrete system.
