# R3T: Rapidly-exploring Random Reachable Set Tree for Optimal Kinodynamic Planning of Nonlinear Hybrid Systems

> [!info] Wu, Albert; Sadraddini, Sadra; Tedrake, Russ · 2020 · 2020 IEEE International Conference on Robotics and Automation (ICRA)

## Summary
> [!note] AI-drafted from the abstract — a base to refine.
**TL;DR** — R3T is a reachability-based variant of RRT for optimal kinodynamic planning in nonlinear and hybrid systems, growing the tree over approximated reachable sets rather than sampled states.
**Problem** — Sampling-based kinodynamic planning is hard in nonlinear and especially hybrid/contact-rich systems, where distinct dynamic modes complicate reachability and steering.
**Method** — Approximates reachable sets using polytopes and performs sampling-based planning over them; in hybrid systems, different dynamic modes within a reachable set are represented explicitly by multiple polytopes. Optimality is recovered through RRT*-style rewiring.
**Key results** — Proves R3T is probabilistically complete for kinodynamic systems and asymptotically optimal via rewiring, and notes it doubles as a formal reachability-analysis/verification tool; demonstrated on nonlinear, hybrid, and contact-rich robotic case studies.

## Takeaways
- Plans in reachable-set space (polytopes) instead of point states, which sidesteps the two-point boundary-value steering problem of classic kinodynamic RRT.
- Multi-polytope reachable sets are what let it handle mode switches in hybrid/contact dynamics explicitly.
- Comes with completeness + asymptotic-optimality guarantees and a reachability-verification byproduct.

## Relevance to your work
Contact-rich hybrid systems and reachability-based planning are directly relevant to legged locomotion, where footstep/contact modes make the dynamics hybrid; R3T offers a formally-grounded planner for such systems.

## Abstract (from bib)
We introduce R3T, a reachability-based variant of the rapidly-exploring random tree (RRT) algorithm that is suitable for (optimal) kinodynamic planning in nonlinear and hybrid systems. We developed tools to approximate reachable sets using polytopes and perform sampling-based planning with them. This method has a unique advantage in hybrid systems: different dynamic modes in the reachable set can be explicitly represented using multiple polytopes. We prove that under mild assumptions, R3T is probabilistically complete in kinodynamic systems, and asymptotically optimal through rewiring. Moreover, R3T provides a formal verification method for reachability analysis of nonlinear systems.
