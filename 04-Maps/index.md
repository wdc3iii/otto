# 04 · Maps

**Maps of Content (MOCs)** — hand-curated hub notes, one per subfield, that link
**both concepts and papers** and state the narrative arc through them. This is the
backbone of a literature review and often becomes a paper/talk outline.

Guidance:
- A MOC is a *note that links to notes*, arranged by your own logic — not a folder, not a tag.
- Group links by sub-question / method / chronology; add a one-line note on *why* each link matters.
- **Create a MOC only when a cluster is big enough to need navigation** — empty scaffolding is maintenance debt.
- Filename = kebab-case (`bipedal-locomotion-control.md`). Add it to [[Home]].
- Consider embedding a Bases view (`file.hasLink(this.file)`) so the MOC auto-lists inbound notes.

Built / updated by the `lit-review` skill. Contradictions between existing notes and new
sources are the interesting part — flag them here.
